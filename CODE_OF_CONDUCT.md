# Code of Conduct

## Our Commitment

We are committed to providing a welcoming and inclusive environment for all contributors and users of the Travel Agency Enhanced project. We expect all members of our community to treat each other with respect and professionalism.

## Our Standards

Examples of behavior that contribute to creating a positive environment include:

- **Being respectful** - Respect different opinions, experiences, and perspectives
- **Being inclusive** - Welcome and encourage participation from everyone
- **Being professional** - Keep communications professional and constructive
- **Being supportive** - Help other community members and celebrate successes
- **Giving credit** - Acknowledge and credit others' contributions
- **Listening actively** - Listen to understand rather than to respond
- **Providing feedback constructively** - Offer helpful feedback in a kind manner

Examples of unacceptable behavior include:

- **Harassment** - Any form of harassment based on protected characteristics
- **Discrimination** - Discrimination based on race, ethnicity, gender, sexual orientation, religion, disability, or other characteristics
- **Intimidation** - Threatening, intimidating, or hostile behavior
- **Hate speech** - Using slurs, discriminatory language, or hateful speech
- **Spam** - Excessive self-promotion or off-topic spam
- **Trolling** - Deliberately inflammatory or off-topic messages
- **Doxxing** - Sharing personal information without consent
- **Sexual harassment** - Unwelcome sexual comments, advances, or jokes

---

## Our Responsibilities

Project maintainers are responsible for:

- Clarifying standards of acceptable behavior
- Enforcing this Code of Conduct fairly
- Protecting the privacy of those reporting violations
- Maintaining a welcoming and safe community
- Taking appropriate corrective action

---

## Scope

This Code of Conduct applies to all project spaces including:

- GitHub repository (issues, pull requests, discussions)
- Documentation and comments
- Project meetings and events
- Social media related to the project
- Any other spaces managed by the project community

This Code of Conduct also applies to official project representatives acting outside project spaces.

---

## Enforcement

### Reporting Violations

If you witness or experience behavior that violates this Code of Conduct:

1. **Document** - Take note of what happened, when, and who was involved
2. **Contact** - Report to the project maintainers
3. **Provide details** - Include as much information as possible

**Reporting Methods:**

- **Email:** conduct@travel-agency.com
- **GitHub:** Open a private issue with "CODE OF CONDUCT" in title
- **Trusted contact:** Reach out to a project maintainer directly

All reports will be:
- Treated confidentially
- Investigated promptly
- Handled fairly
- Kept private unless disclosure is necessary

### Consequences

Violations of this Code of Conduct may result in:

1. **Warning** - A private written warning from maintainers
2. **Temporary ban** - Suspension from project spaces (7-30 days)
3. **Permanent ban** - Removal from project spaces
4. **Report to authorities** - In severe cases involving threats or harm

Consequences are determined on a case-by-case basis and are proportional to the violation.

### Appeal Process

If you believe you have been treated unfairly:

1. **Request review** - Contact the Code of Conduct committee
2. **Present your case** - Provide your perspective
3. **Wait for decision** - Committee will review and respond
4. **Closure** - Final decision will be communicated

## Examples

### ✅ GOOD: Constructive Feedback

```
"I've noticed that the user authentication logic could be improved. 
Would you consider adding two-factor authentication? This would 
enhance security. Here's a reference implementation if helpful."
```

### ❌ BAD: Dismissive Criticism

```
"Your code is terrible. You clearly don't know what you're doing."
```

### ✅ GOOD: Disagreement

```
"I see your point, but I think there might be a different approach that 
would be more performant. Could we discuss the trade-offs?"
```

### ❌ BAD: Aggressive Disagreement

```
"That's stupid. Only an idiot would implement it that way."
```

### ✅ GOOD: Respectful Correction

```
"I believe there might be a small issue with the SQL query. 
It could be vulnerable to SQL injection. Here's a link to a 
secure alternative."
```

### ❌ BAD: Condescending Correction

```
"Wow, you don't even know about SQL injection? This is basic stuff."
```

## Community Guidelines

### Inclusive Language

Use inclusive language:
- Use "they/them" if pronouns are unknown
- Avoid gendered language ("guys" → "everyone", "him/her" → "them")
- Be mindful of cultural differences and contexts
- Ask if you're unsure about terminology

### Issue Discussions

- Stay on topic
- Be constructive and respectful
- No personal attacks or insults
- Separate criticism of ideas from criticism of people
- Assume good intent but address impacts

### Pull Request Reviews

- Focus on the code, not the person
- Ask questions if something is unclear
- Provide concrete suggestions for improvement
- Acknowledge good work and effort
- Be patient with new contributors
- Help them learn and improve

### Events and Meetings

- Respect all participants
- Allow everyone to speak
- Don't interrupt or talk over others
- Be inclusive of different communication styles
- No harassment or discriminatory behavior
